✨ Air-Drawing Recognition

A computer vision application that lets you trace shapes mid-air and manipulate canvas elements using hand gestures in real-time!

🖐️ Supported Gestures

  • 👆 Point (Index Finger) — Draw / trace shapes in mid-air
  • ✌️ Peace Sign — Toggle Move Mode (Pan & Zoom using both hands)
  • 🖖 Three Fingers Up — Undo last shape
  • ✋ Open Palm — Redo last shape
  • 👌 OK Sign — Clear canvas
  • 👍 Thumbs Up — Cycle drawing color

🚀 How to Run Locally

Clone the repository and install dependencies:

pip install opencv-python mediapipe numpy
python draw.py
